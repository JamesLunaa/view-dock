# view-dock

view-dock is an open-source project that turns an iPad into a secondary display for
an Arch Linux machine, connecting over Wi-Fi (same network) or wired via USB. It
consists of a Python host application running on Arch that creates a virtual
display and streams it over WebRTC, and a native iPadOS app that renders the stream
and forwards touch input back to the host — giving you a real extended desktop
rather than a simple screen mirror.

This project is currently in early development and not yet usable end-to-end.
Contributions, ideas, and feedback are welcome as the project takes shape.
